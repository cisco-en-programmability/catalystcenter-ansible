.. Title

cisco.catalystcenter.compliance_sites_policys_violations_info module -- Information module for Compliance Sites Policys Violations
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++

.. Collection note

.. note::
    This module is part of the `cisco.catalystcenter collection <https://galaxy.ansible.com/cisco/catalystcenter>`_ (version 2.11.0).

    To install it, use: :code:`ansible-galaxy collection install cisco.catalystcenter`.
    You need further requirements to be able to use this module,
    see :ref:`Requirements <ansible_collections.cisco.catalystcenter.compliance_sites_policys_violations_info_module_requirements>` for details.

    To use it in a playbook, specify: :code:`cisco.catalystcenter.compliance_sites_policys_violations_info`.

Synopsis
--------

.. Description

- Get all Compliance Sites Policys Violations.
- Get Compliance Sites Policys Violations by id.
- Retrieves the violations for a specific compliance policy.
- Returns a specific compliance policy violation for a site.

.. note::
    This module has a corresponding :ref:`action plugin <action_plugins>`.

.. Notes

Notes
-----

.. note::
   - SDK Method used are compliance.Compliance.retrieve\_a\_specific\_policy\_violation, compliance.Compliance.retrieve\_the\_violations\_for\_a\_policy,
   - Paths used are get /dna/intent/api/v1/compliance/sites/{siteId}/policys/{policyId}/violations, get /dna/intent/api/v1/compliance/sites/{siteId}/policys/{policyId}/violations/{violationId},
   - Supports \ :literal:`check\_mode`\ 
   - The plugin runs on the control node and does not use any ansible connection plugins,
   - but instead uses the embedded connection manager from Cisco CATALYST SDK
   - Requires Python \>= 3.10, matching the controller Python versions supported by the collection's minimum ansible-core version (see the collection README for the current ansible-core / Python compatibility range)
