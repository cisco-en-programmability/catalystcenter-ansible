cisco.catalystcenter.wireless_settings_pre_auth_acls module -- Resource module for Wireless Settings Pre Auth Acls
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++

.. Collection note

.. note::
    This module is part of the `cisco.catalystcenter collection <https://galaxy.ansible.com/cisco/catalystcenter>`_ (version 2.11.0).

Synopsis
--------

.. Description

- Manage operations create, update and delete of the resource Wireless Settings Pre Auth Acls. - \> This API allows users to create a Pre-Auth ACL design. To configure the created Pre-Auth ACL settings to an IOS-XE wireless supported device,. - \> This API allows users to delete a Pre-Auth ACL by ID. This API will not remove the Pre-Auth ACL configured on a controller. To remove the provisioned Pre-Auth ACL settings from an IOS-XE wireless supported device,. - \> This API allows users to update the details of an existing Pre-Auth ACL by ID. To configure the modified Pre- Auth ACL settings to an IOS-XE wireless supported device,.

.. note::
    This module has a corresponding :ref:`action plugin <action_plugins>`.

   - Paths used are post /dna/intent/api/v1/wirelessSettings/preAuthAcls, delete /dna/intent/api/v1/wirelessSettings/preAuthAcls/{id}, put /dna/intent/api/v1/wirelessSettings/preAuthAcls/{id},
   - Does not support \ :literal:`check\_mode`\ 
   - The plugin runs on the control node and does not use any ansible connection plugins,
   - but instead uses the embedded connection manager from Cisco CATALYST SDK
   - Requires Python \>= 3.10, matching the controller Python versions supported by the collection's minimum ansible-core version (see the collection README for the current ansible-core / Python compatibility range)
