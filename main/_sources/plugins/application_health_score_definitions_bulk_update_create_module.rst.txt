.. Title

cisco.catalystcenter.application_health_score_definitions_bulk_update_create module -- Resource module for Application Health Score Definitions Bulk Update Create
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++

.. Collection note

.. note::
    This module is part of the `cisco.catalystcenter collection <https://galaxy.ansible.com/cisco/catalystcenter>`_ (version 2.11.0).

    To install it, use: :code:`ansible-galaxy collection install cisco.catalystcenter`.
    You need further requirements to be able to use this module,
    see :ref:`Requirements <ansible_collections.cisco.catalystcenter.application_health_score_definitions_bulk_update_create_module_requirements>` for details.

    To use it in a playbook, specify: :code:`cisco.catalystcenter.application_health_score_definitions_bulk_update_create`.

Synopsis
--------

.. Description

- Manage operation create of the resource Application Health Score Definitions Bulk Update Create. - \> Caller ID is used to trace the origin of API calls and their associated queries executed on the database. It's an optional header parameter that can be added to an API request.

.. note::
    This module has a corresponding :ref:`action plugin <action_plugins>`.

.. Notes

Notes
-----

.. note::
   - SDK Method used are applications.Applications.bulk\_update\_application\_health\_score\_definitions,
   - Paths used are post /dna/intent/api/v1/applicationHealthScoreDefinitions/bulkUpdate,
   - Does not support \ :literal:`check\_mode`\ 
   - The plugin runs on the control node and does not use any ansible connection plugins,
   - but instead uses the embedded connection manager from Cisco CATALYST SDK
   - Requires Python \>= 3.10, matching the controller Python versions supported by the collection's minimum ansible-core version (see the collection README for the current ansible-core / Python compatibility range)
