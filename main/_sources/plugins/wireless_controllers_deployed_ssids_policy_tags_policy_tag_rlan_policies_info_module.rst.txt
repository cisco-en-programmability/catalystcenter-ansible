Synopsis

.. Description

- Get all Wireless Controllers Deployed Ssids Policy Tags Policy Tag Rlan Policies.
- Get Wireless Controllers Deployed Ssids Policy Tags Policy Tag Rlan Policies by id. - \> This API operation returns the configurations for a specific instance of PolicyTagRlanPolicy feature on a wireless controller, and this API is applicable for per-device based configuration. - \> This API operation returns the configurations for a specific instance of a PolicyTagRlanPolicy feature on a wireless controller, and this API is applicable for per-device based configuration.

    This module has a corresponding :ref:`action plugin <action_plugins>`.

.. Notes

Notes
-----

.. note::
   - SDK Method used are wireless.Wireless.get\_configurations\_for\_a\_specific\_instance\_of\_a\_policy\_tag\_rlan\_policy\_feature\_on\_a\_wireless\_controller\_connectivity, wireless.Wireless.get\_configurations\_for\_ssid\_feature\_on\_a\_wireless\_controller,
   - Paths used are get /dna/campus/api/v1/wirelessControllers/{networkDeviceId}/deployed/ssids/policyTags/{policyTagId}/policyTagRlanPolicies, get /dna/campus/api/v1/wirelessControllers/{networkDeviceId}/deployed/ssids/policyTags/{policyTagId}/policyTagRlanPolicies/{id},
   - Supports \ :literal:`check\_mode`\ 
   - The plugin runs on the control node and does not use any ansible connection plugins,
   - but instead uses the embedded connection manager from Cisco CATALYST SDK
   - Requires Python \>= 3.10, matching the controller Python versions supported by the collection's minimum ansible-core version (see the collection README for the current ansible-core / Python compatibility range)
